# دليل المناقشة الفنية

React للعرض والتفاعل، وLaravel لتسجيل الدخول والصلاحيات والتحقق والحسابات والتواصل مع المزوّد. PostgreSQL هي مصدر البيانات.

المستخدم عنده عدة عملاء، والعميل عنده عدة صفقات. ملكية الصفقة جاية من العميل، من غير تكرار user_id. كل استعلام مقيد بالمستخدم الحالي، ومعاه Policy للتفاصيل. طلب ID لحساب تاني يرجع 404، حتى لو اللي طلبه الـAI.

Pipeline هي قيمة Lead وQualified وProposal وNegotiation. Won وLost منفصلين. المبالغ NUMERIC وبترجع strings لحفظ الدقة. الشهر الحالي بتوقيت القاهرة. تاريخ الإغلاق المتوقع مش تاريخ تحقيق الإيراد، ومن غير سجل تاريخي ما نقدرش نثبت نمو المبيعات.

الـAI يختار أداة قراءة ومعاملاتها. السيرفر يتحقق ويطبق المستخدم الحالي وينفذ الاستعلام. بعد كده يبعت سياق محدود لصياغة الإجابة. الموديل ما عندوش اتصال مباشر بالـdatabase أو SQL أو أدوات تعديل. التقرير والملخص يستخدموا نفس الحسابات.

الأرقام في النص تستخدم placeholders يملؤها السيرفر، والمصادر لازم تكون ضمن سجلات النتيجة المسموح بها. ده يقلل الأخطاء لكنه مش ضمان لصحة أي استنتاج لغوي؛ التوصيات محتاجة مراجعة وتقييم حي.

المفتاح في backend .env فقط. بيانات الاتصال مستبعدة، والملاحظات يتم تقليلها وتنقيحها قدر الإمكان؛ التنقيح الآلي مش ضمان كامل. تعليمات داخل الملاحظات تعامل كنص غير موثوق، وما تغيرش الصلاحيات. البيانات التجريبية وهمية.

فيه اختبارات PostgreSQL للعلاقات والعزل والحسابات، واختبارات AI ببديل ثابت، واختبارات HTTP للمزوّد، واختبارات واجهة ومتصفح. اتضاف دعم Gemini بمفتاح محفوظ محليًا فقط. الاختبارات الحية اختيارية باستخدام RUN_LIVE_AI=1 وتستهلك حصة المزوّد؛ اذكر نتائجها الفعلية منفصلة عن الاختبارات الثابتة وأي أخطاء خارجية.

قبل المناقشة شغّل الاختبارات واقرأ الخدمات وجرّب تعديل بسيط بنفسك. جهّز شرح مشكلة تسجيل الخروج وإزاي اختبار المتصفح كشفها وإزاي اتصلحت.
